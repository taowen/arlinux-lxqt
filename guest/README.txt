Arlinux LXQt

This distribution provides a conventional LXQt desktop on Debian Testing.
Open the application menu to start QTerminal, PCManFM-Qt, or LXQt settings.

Install additional ARM64 packages with Debian's standard package manager:

  sudo apt update
  sudo apt install package-name

Desktop packages come from Debian Testing through the Tsinghua mirror.
Android supplies the display, input, audio,
network, device lock, and application lifecycle.
