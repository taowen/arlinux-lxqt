Arlinux LXQt

This distribution provides a conventional LXQt desktop on Debian Sid. Open the
application menu to start QTerminal, PCManFM-Qt, or LXQt settings.

Install additional ARM64 packages with Debian's standard package manager:

  sudo apt update
  sudo apt install package-name

The default repository is a tested Debian archive snapshot. It is intentionally
not an unbounded Sid mirror. Android supplies the display, input, audio,
network, device lock, and application lifecycle.
